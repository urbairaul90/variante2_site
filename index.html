O HTML (HyperText Markup Language) é a linguagem base para a construção de páginas Web. Com ele, aprendemos a estruturar o conteúdo de uma página através de títulos, parágrafos, imagens, ligações e tabelas.

O CSS (Cascading Style Sheets) é a linguagem usada para formatar e dar aparência às páginas Web. Utilizando um ficheiro CSS externo, é possível aplicar cores, tipos de letra e alinhamentos a várias páginas ao mesmo tempo.
